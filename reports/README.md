# Reports folder

Created by `python main.py` (all values measured in that run):

| File | Content |
|---|---|
| `model_comparison.csv` | Accuracy, macro/weighted precision, recall, F1, fit time, cross-validation macro-F1 |
| `classification_report_<model>.txt` | Per-class precision, recall, F1, support for each model |
| `data_report.json` | Every cleaning step with the number of removed rows |
| `top_features_best_model.csv` | Most informative terms per class (best model) |
| `results_report.md` | Human-readable summary of the run |
| `report_template.md` | Blank academic report template to fill in with the numbers above |
